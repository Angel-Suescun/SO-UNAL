# Sistemas Operativos — Módulos del Kernel

## Descripción general

Este repositorio contiene el código fuente, los comandos y la documentación desarrollados para la asignatura de Sistemas Operativos. A través de ejercicios prácticos, se exploran conceptos fundamentales de los sistemas operativos, con énfasis en su implementación y funcionamiento en entornos Linux.

El proyecto está organizado en secciones que documentan el proceso de desarrollo, las pruebas realizadas, los resultados obtenidos y los conceptos teóricos relacionados con cada ejercicio.

## Objetivos

- Comprender los conceptos fundamentales de los sistemas operativos mediante ejercicios prácticos.
- Implementar y probar programas en C dentro de un entorno Linux.
- Explorar los mecanismos internos del sistema operativo a través de ejemplos de código.
- Documentar los procedimientos de compilación, ejecución y verificación.
- Relacionar los resultados obtenidos con los conceptos teóricos estudiados en la asignatura.
- Preparar explicaciones técnicas que permitan comprender y sustentar las implementaciones realizadas.

## Estructura del repositorio

El repositorio se organiza en directorios correspondientes a las diferentes prácticas y secciones del proyecto. Cada sección puede incluir código fuente, archivos de compilación, comandos de ejecución y documentación de apoyo.

## Entorno de desarrollo

- **Sistema operativo:** Ubuntu Linux.
- **Lenguaje de programación:** C.
- **Sistema de compilación:** GNU Make.
- **Entorno de pruebas:** máquina virtual Linux.
- **Herramientas:** encabezados del kernel de Linux y utilidades para la administración de módulos.

## Referencia bibliográfica

Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10.ª ed.). Wiley.

Esta obra constituye la referencia bibliográfica principal para el estudio de los conceptos teóricos relacionados con las prácticas desarrolladas en el repositorio. También se consulta la documentación técnica pertinente de Linux cuando resulta necesario.

## Propósito académico

Este repositorio constituye un registro del desarrollo, la implementación, las pruebas y el análisis de los ejercicios realizados durante la asignatura. Su propósito es fortalecer la comprensión de los mecanismos de los sistemas operativos mediante la experimentación práctica, la documentación técnica y la explicación fundamentada de los resultados obtenidos.
